About the project

What the system does, and how it decides.

This is a local-first, production-oriented intrusion detection prototype that fuses a supervised gradient-boosting classifier (CatBoost) with an unsupervised anomaly detector (Local Outlier Factor) trained only on benign traffic. A flow is flagged as an attack if either model raises an alert — an OR-voting strategy that trades some precision for higher recall, which matters more when the cost of a missed intrusion outweighs the cost of a false alarm.

The pipeline was built with leakage awareness in mind: a strict chronological train/test split (no shuffling), a scaler fit exclusively on training data, and an aggressive class-imbalance strategy (undersampling + SMOTE + ADASYN) to handle the reality that most network traffic is benign. Results below come from training on 2,300,825 labeled flow records with 78 extracted features per flow. Inference is served through a Streamlit dashboard (app.py).

How it decides

CatBoost classifier

Supervised gradient boosting trained with class-balanced weights on the full feature set, tuned for AUC. Handles the majority of clear-cut attack/benign separations.

Local Outlier Factor

Trained only on benign traffic in novelty mode. Flags flows that look statistically unlike normal behavior, catching attack patterns the classifier alone might miss.

OR-voting fusion

A flow is marked malicious if either model fires. This favors recall — fewer missed intrusions — at the cost of some extra false positives.

Leakage-aware pipeline

Chronological (non-shuffled) train/test split, training-only scaler fitting, and automated leakage warnings when metrics look suspiciously high.
